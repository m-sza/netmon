    Page hook A small script netmon runs inside pages, to record WebSocket messages and which script started each request. Pages can tell it's there (nothing else netmon does is visible to them), so turn it off for sites that check for it. Where it's off, WebSocket messages and “Started by script” aren't recorded; everything else is.
    Changes apply when a page loads. Reload the tab
